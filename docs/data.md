## Срез эксперимента

Фильтр: `competition_id == "GB1" and 2012 <= season <= 2024`.
Результат — **4 940 записей**, **13 сезонов**, по **380 матчей** в каждом.
Это все подходящие записи архива, а не случайная выборка. Сезон 2025/26 исключён заранее, а не по величине результата.

| Поле | Смысл | Проверка |
| --- | --- | --- |
| game_id | Идентификатор матча | Целое, уникально |
| competition_id | Код соревнования | Ровно GB1 |
| season | Год начала сезона | 2012–2024 |
| date | Дата матча | ISO YYYY-MM-DD, год season или season+1 |
| home_club_goals | Голы номинальных хозяев | Целое от 0 до 30 |
| away_club_goals | Голы номинальных гостей | Целое от 0 до 30 |

Пустых значений голов в выбранном срезе нет. Идентификаторы уникальны.
Никакие отсутствующие результаты не заменяются нулями, даты разбираются явно.
Проверка 380 записей — диагностический контроль текущей версии набора, а не универсальное требование к любому чемпионату.

## Обработка предупреждений профилировщика

- `date` хранится текстом: преобразуется через `date.fromisoformat`.
- `aggregate` ошибочно распознано как дата из-за значений вида `2:1`: это счёт, поле не используется и не парсится как дата.
- `total_market_value` в clubs и `coach_name` в national_teams полностью пусты; они не участвуют в исследовании.
- Пропуски международной статистики игроков и сроков контрактов не заполняются, поскольку соответствующие таблицы исключены из расчёта.
- Суммы `game_id`, `season` и ID клубов не имеют содержательного смысла; автоматические rate hints по этим колонкам игнорируются как неприменимые.
- Последний день всего архива не сравнивается с полными периодами; в эксперименте сравниваются выбранные сезоны, а не «последний день».

## Воспроизведение извлечения

```bash
python scripts/extract_data.py /path/to/archive.zip
python scripts/experiment.py --force
python scripts/verify_results.py
```

Скрипт читает только `games.csv` внутри ZIP, выбирает шесть полей, сортирует по сезону, дате и ID.
Исходные данные сохраняются неизменными, результат извлечения и SHA-256 записываются отдельно.
`data/manifest.json` содержит хеш архива, хеш исходного games.csv, правило фильтрации и версию набора.

## Что означает «домашняя победа»

Победа Home — только неравенство `home_club_goals > away_club_goals` в этой записи.
Это не проверка того, где физически проходил матч. Сила команд и прочие конфаундеры не учитываются.
Для причинного исследования потребовались бы дополнительные признаки, проверка нейтральных полей и отдельная статистическая модель.
