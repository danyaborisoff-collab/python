## Что исследуется

Меняется ли доля побед номинальных хозяев в английской Премьер-лиге между сезонами?
Для анализа выделены матчи `competition_id=GB1` за сезоны 2012/13–2024/25 из предоставленного архива.
Расчёт читает CSV, проверяет данные, формирует таблицу и интерактивный график, а затем MkDocs собирает сайт.

## Архитектура

```text
archive.zip / games.csv
  └── scripts/extract_data.py (одноразовое извлечение)
       └── data/matches.csv + data/manifest.json
            └── scripts/experiment.py
                 ├── валидация схемы и значений
                 ├── SHA-256 → .cache/experiment/<key>.json
                 └── docs/generated/{results.md, results.json, season_summary.csv, home-wins.html}
                      └── mkdocs build --strict
                           └── site/ → Pages / SSH-хостинг → HTTP 200 + RESEARCH-SITE-OK
```

Это описательный эксперимент, а не оценка причинного эффекта стадиона или COVID-19.

Исходный архив, персональные поля игроков и токены в проект не включены.
