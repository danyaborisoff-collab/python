## Документация

1. [Каталог SSG Jamstack](https://jamstack.org/generators/) — исходная ссылка задания.
2. [Материал курса на Яндекс Диске](https://disk.yandex.ru/i/RRaTxrn5psk7ZQ) — видео «0. Публикация на GitHub Pages на основе Hugo + Jekyll.webm». Название проверено; содержание видео автоматически не транскрибировалось. Проект использует требуемый Python SSG, не Hugo/Jekyll.
3. [MkDocs: configuration](https://www.mkdocs.org/user-guide/configuration/) — строгая сборка и URL.
4. [Material: search](https://squidfunk.github.io/mkdocs-material/setup/setting-up-site-search/) — локальный поиск и языки.
5. [nbconvert: executing notebooks](https://nbconvert.readthedocs.io/en/latest/execute_api.html).
6. [MyST-NB: execute and cache](https://myst-nb.readthedocs.io/en/latest/computation/execute.html).
7. [Quarto: managing execution](https://quarto.org/docs/projects/code-execution.html).
8. [papermill: parameterize](https://papermill.readthedocs.io/en/latest/usage-parameterize.html).
9. [GitHub Actions limits](https://docs.github.com/en/actions/reference/limits).
10. [Custom workflow for Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
11. [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
12. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Источники о поведении инструментов не являются источником футбольных значений:
все значения эксперимента вычислены из пользовательского архива.
